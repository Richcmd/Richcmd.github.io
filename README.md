# RICH CMD v6.7.7 — Communicatie Planner Pro + VRO Inventaris

Deze build werkt verder op v6.7.6 en voegt twee workflowlagen toe.

## Communicatie Planner Pro
- Vandaag opvolgen
- Open communicatie
- Snelle notities
- Overdracht Generator Pro
- Afgeronde communicatie
- Rollenlijst: Filiaalmanager, Manager Vers/Service, Manager Operatie, Teamleider en Collega
- Opvolgingen met prioriteit, status, rol, optionele naam en opvolgdatum
- Snelle acties voor +1 dag en +1 week
- Snelle notities omzetten naar opvolging of toevoegen aan overdracht

## VRO Inventaris inladen
De app bevat nu de VRO-lijst uit de aangeleverde Excel-sheet:
- NASA nummer
- Schapsticker omschrijving
- Ass Omschrijving / categorie
- Werkblad als afdeling
- Gebruikstekst waar beschikbaar

Aantal unieke bronartikelen: 502.

Artikelen worden niet automatisch toegevoegd aan bestaande gebruikersdata. Gebruik in Inventaris de knop **VRO-lijst inladen**. De import dedupliceert op NASA nummer + naam.
